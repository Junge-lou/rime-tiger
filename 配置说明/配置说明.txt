虎码 Rime 配置说明
==================

这份说明给第一次接触本配置的人看。想调候选数、样式、按键，先看第四节。
根目录里的 *.schema.yaml、*.custom.yaml 不要移动，Rime 会按这些文件名读取配置。
同目录有两份示例文件：
- 《示例.schema.yaml》：一份带中文注释的 schema 示例。
- 《示例.custom.yaml》：一份带中文注释的 custom 示例。
这两份只放在配置说明里给人看，Rime 不会读取。


一、相比原版整理了什么
--------------------------

1. 常用字和全字集改回同一方案内切换
   tiger / tigress 底层加载全字集词典，默认用 core2022 过滤到常用字。
   按 Ctrl+H 或 Ctrl+Shift+H 可在“常用字”和“全字集”之间切换。
   extended_char 关为常用字，开为全字集；不写 reset，避免新窗口重置。
   字集状态已加入 save_options，并由 option_sync 做跨窗口同步。

2. 全字集不再作为独立方案
   默认方案列表只显示 tiger / tigress / PY_c。
   tiger / tigress 使用各自的 .extended 词典入口，常用字和全字集由同一个开关切换。
   旧用户如果之前停在已删除旧方案，部署后重新选择一次 tiger 或 tigress 即可。

3. 虎码方案共享公共底座
   大部分按键、滤镜、符号、反查、空码处理都放在 tiger_base.schema.yaml。
   虎码共用的用户补丁放在 tiger_base.custom.yaml。
   修改公共配置时，不需要在多个文件里重复改。

4. 两个虎码方案都支持加词、删词、调序
   tiger 和 tigress 共用同一套用户词管理逻辑，当前方案的单字或词语候选都可操作。
   两个方案的新增内容分别写入各自用户词库，不会互相串用。

5. 方案名保持简洁
   切换方案时只显示方案名；字数保留在各方案 description 里。


二、方案和字集怎么选
------------------

1. tiger
   虎码单字
   底层字典：全字集 99144 字
   默认常用字过滤，适合只打单字，也支持加词、删词、调序。

2. tigress
   虎码词库
   底层字典：全字集 99144 字
   默认常用字过滤
   适合日常打词，支持加词、删词、调序。

3. PY_c
   拼音方案

推荐：
- 日常输入用 tigress。
- 只想打单字用 tiger。
- 需要生僻字、扩展字时，在 tiger 或 tigress 里按 Ctrl+H 切到全字集。


三、配置文件分工
----------------

每个真实方案都有两类文件：

1. *.schema.yaml
   方案本体。这里放方案名、词典入口、处理流程。

2. *.custom.yaml
   用户补丁。这里放候选数、样式、按键、开关。

一般优先改 *.custom.yaml。只有要改方案名、词典入口、处理流程时，再改
*.schema.yaml。

Rime 的方案字段叫 schema。tiger_base.schema.yaml 里也有 schema_id、name、
description，方便阅读和继承；不要把 tiger_base 加入方案列表。


四、继承关系
------------

schema 关系：

  tiger_base.schema.yaml
  ├─ tiger.schema.yaml               单字用户方案
  └─ tigress.schema.yaml             词库用户方案

custom 关系：

  tiger_base.custom.yaml
  ├─ tiger.custom.yaml               单字用户方案补丁
  └─ tigress.custom.yaml             词库用户方案补丁

读法：
- 上面的文件先加载。
- 下面的文件继承上面的配置，并覆盖自己的差异。


五、想改配置，改哪个文件
------------------------

1. 虎码方案都生效
   改 tiger_base.custom.yaml。

   适合：候选数量、候选编号、外观样式、通用按键。

2. 只改单字方案：tiger
   改 tiger.custom.yaml。

3. 只改词库方案：tigress
   改 tigress.custom.yaml。

4. 只改方案名或词典入口
   改对应的 *.schema.yaml。

常见例子：
- 想把候选数从 9 改成 5：改 tiger_base.custom.yaml。
- 只想词库版启用某个样式：改 tigress.custom.yaml。
- 只想词库改一个特殊按键：改 tigress.custom.yaml。
- 想改方案在切换菜单里的名字：改对应的 *.schema.yaml。

次选键跳过表情和符号联想：
- 默认开启。普通输入时，分号 ; 选择第 2 个文字候选，单引号 ' 选择第 3 个文字候选，
  中间的 emoji 和符号联想不占用这两个次选键。
- 如果目标文字不在第一页，会继续检查后续候选；为避免异常长候选链影响响应，最多检查 512 项。
- 反斜杠符号菜单（如 \\bq）和分号引导输入仍按候选位置选重，不受智能次选影响。
- 如需恢复原来的位置选重，在 tiger_base.custom.yaml 的 patch 下加入：

  smart_candidate_selection/enabled: false  # ; 选第 2 项，' 选第 3 项

  这是静态配置，修改后需要重新部署 Rime 才会生效。


六、常用字和全字集怎么来的
--------------------------

单字版：
- tiger 使用 tiger.extended。
- 默认用 core2022 过滤为常用字；切到全字集时不过滤。

词库版：
- tigress 使用 tigress.extended。
- 默认用 core2022 过滤为常用字；切到全字集时不过滤。

全字集包含常用字。当前统计：
- 常用字：9767 字
- 全字集：99144 字


七、加词、删词、调序
--------------------

启用范围：
- tiger
- tigress

快捷键：
- 编码 + \\ + Space：在目标编码后连续输入两个反斜杠，再按空格进入加词
- Shift+Delete 或 Ctrl+Delete：删除当前高亮候选
- Ctrl+Shift+M：有编码时管理当前编码；空输入时打开全局管理
- Ctrl+方向键 调整候选顺序
- macOS 可用 Ctrl+Option+方向键

加词只保留双反斜杠入口。
以反斜杠开头的 \\djs、\\tj 等命令不匹配加词后缀，会继续按原命令处理。

官方词可以删除。删除不会改官方 YAML，而是在 LevelDB 中写入隐藏记录，更新词库后仍
保持隐藏，并可在管理器中恢复。同码同词既是快捷加词又是官方词时，删除会同时取消
快捷新增并隐藏官方候选。

当前编码管理可恢复隐藏项，Ctrl+0 可清除当前编码的隐藏和手动调序。全局管理分为
“已隐藏”“手动调序”“快捷加词”，支持按编码筛选。管理器只操作快捷记录，不编辑
tiger.user.dict.yaml / tigress.user.dict.yaml。

两个方案继续加载各自的手工用户词典：
- tiger -> tiger.user.dict.yaml
- tigress -> tigress.user.dict.yaml

快捷键产生的加词、减词、调序记录现在保存在 Rime 用户数据库中，不再改写官方
码表。首次加载新版 Lua 时，会把已有的用户词典内容和旧版禁用标记迁移进去；之后
更新官方码表不会覆盖这些操作记录。

用户数据位置：
- 手工维护的词条：tiger.user.dict.yaml / tigress.user.dict.yaml
- tiger 快捷键操作：LevelDB 数据库 tiger_user_words_tiger
- tigress 快捷键操作：LevelDB 数据库 tiger_user_words_tigress

这些文件和数据库都在 Rime 用户数据目录中。常见位置：
- macOS 鼠须管：~/Library/Rime
- Windows 小狼毫：%APPDATA%\Rime
- Linux Fcitx5：~/.local/share/fcitx5/rime（其他前端可能不同）

LevelDB 的实际文件名或后缀可能随 Rime 版本和前端不同，请勿直接编辑。需要备份时，
直接备份整个 Rime 用户数据目录即可。首次升级并重新部署前，请先保留原来的两个
*.user.dict.yaml，以便新版逻辑完成一次迁移。


八、不要动这些
--------------

1. 不要把 *.schema.yaml / *.custom.yaml 移进文件夹。
   Rime 在根目录按文件名读取它们。

2. 不要把 tiger_base 加进 default.custom.yaml 的 schema_list。
   tiger_base 是公共底座，放进方案列表会让切换菜单出现一个不该选的配置项。

3. 不要删除 tiger_base.schema.yaml / tiger_base.custom.yaml。
   虎码方案都依赖它们。

九、改完怎么生效
----------------

改完配置后重新部署 Rime。

macOS 鼠须管：
从输入法菜单选择“重新部署”。

Windows 小狼毫：
右键输入法图标，选择“重新部署”。

部署失败时，先检查刚改过的 YAML 缩进，尤其是冒号后面的空格和列表缩进。
